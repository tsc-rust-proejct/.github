# TSC Rust Project

**Learn Rust. Build Systems. Explore AI Infrastructure.**

Welcome to **TSC Rust Project**!

这是一个专注于 Rust 学习、系统编程和 AI Infrastructure 工程实践的技术组织。

我们希望通过持续学习、代码实践和真实项目，逐步建立扎实的系统编程能力，并探索 Rust 在高性能服务端、云原生基础设施和 AI 工程领域的应用。

---

## 🎯 Our Mission

- **Learn Rust** — 系统学习 Rust 语言、所有权、生命周期、异步编程与并发。
- **Build Engineering Skills** — 通过真实项目掌握网络编程、系统编程和工程化实践。
- **Explore AI Infrastructure** — 探索 Rust 在 AI Infra、Agent Runtime 和高性能服务中的应用。
- **Keep Building** — 坚持代码实践、技术总结和持续迭代。

## 🗺️ Learning Roadmap

| Stage | Topics | Focus |
|---|---|---|
| 01. Fundamentals | Syntax, Ownership, Borrowing, Lifetimes | Rust 基础 |
| 02. Advanced Rust | Traits, Generics, Error Handling, Macros | 进阶语言特性 |
| 03. Async & Concurrency | Tokio, Async/Await, Channels | 异步与并发 |
| 04. Systems Programming | Memory, Networking, OS Interaction | 系统编程 |
| 05. Engineering Practice | CLI, Web Services, Tauri | 工程实战 |
| 06. AI Infrastructure | Agent Runtime, Inference, Distributed Systems | AI 基础设施 |

## 🛠️ Engineering Principles

我们重视的不只是代码能否运行，更关注：

- Understand the fundamentals.
- Write testable and maintainable code.
- Build observable and reliable systems.
- Focus on deployment, operations and scalability.
- Learn by building real-world projects.

## 🌱 Long-term Vision

从 Rust 基础出发，逐步深入系统编程、网络服务、分布式系统，最终探索 AI Infrastructure 的工程化落地。

**Learn deeply. Build continuously. Engineer reliably.**
